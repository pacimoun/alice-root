# Локальный fallback прошивки

`python3 scripts/rooting.py fetch` скачивает официальный OTA Mini 2 в `firmware/yandexmini_2/`.
Образ уже скачан локально; он игнорируется Git. В новом checkout загрузка выполняется автоматически.

Файл имеет расширение `.zip`, но фактически это подписанный CPIO/SWUpdate-пакет.
Он не распаковывается и не изменяется — сервер отдаёт его колонке как есть.
Источник задаётся в `src/alice_root/firmware.py`, сторонние зеркала не используются.
