# Правила проекта

- `src/alice_root` — CLI, установка, откат, SoundCloud и голосовые команды; `station` — компоненты колонки; `scripts` — сборка и инструменты.
- Проверки: `python3 -m unittest discover -s tests -v`, `npm ci && npm test`, `python3 scripts/check-repository.py`.
- Используется текущий релиз upstream. Эталонные манифесты, история патчей и проверки контрольных сумм не нужны.
- Fedora x86_64 и Станция Мини 2. Модули Quasar собираются как ARMhf ELF32, несмотря на aarch64 ядро.
- Не добавлять local config, ключи, браузерные профили, аккаунты, backups и сборочные файлы в Git.
- До изменения программ делать backup. Не перезаписывать чужие файлы и symlink; сохранять откат.
- Тесты, doctor, status и dry-run не изменяют рабочие сервисы, аудио, колонку или роутер.
- Bluetooth — основной звук ПК. Не менять глобальные defaults. Не добавлять native GPT, другое wake word и роутерные компоненты.
- Не выполнять commit или push без команды пользователя. Документация — по-русски, коротко и по актуальным командам.
- `docs/rooting-mini2.md` — обязательный начальный маршрут: локальный root-сервер, постоянный SSH и отключение OTA. Не удалять его при сокращении документации.
